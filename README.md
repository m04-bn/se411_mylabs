# SE411 – Software Construction

This repository contains laboratory work and practical exercises for the
**SE411 – Software Construction** course.

The course labs focus on practical software development and construction
practices using Java and Maven, including unit testing, dependency management,
exception handling, and application logging.

## Labs

### Lab 03 – JUnit Introduction
Introduction to unit testing with JUnit 5.

### Lab 04 – Maven Introduction
Working with Maven projects, dependencies, plugins, JavaFX, and Maven Site.

### Lab 05 – Exception Handling
Implementing custom exceptions and proper exception handling in Java.

### Lab 06 – Logging with SLF4J
Implementing application logging using SLF4J, Logback, and Log4j.

## Technologies

- Java
- Eclipse IDE
- Apache Maven
- JUnit 5
- JavaFX
- SLF4J
- Logback
- Log4j
